This project archives the fifth-edition pages from the 2021 site.

Those routes were `/5e/subclasses`, `/5e/spells`, and `/5e/monsters`. Spells and monsters only rendered a placeholder sentence, so they were not carried over as pages. The subclass browser listed names and a theme label, and did not include any ability text. The names are on the [subclasses](/projects/5e-homebrew/subclasses/) page so they are not lost.

The old Tech page was the same kind of placeholder — the words “Hello World!” and nothing else — so it was not migrated.

This is an archive, not an active ruleset.
